# Consumer Buying Behaviour Analytics

A dashboard-style portfolio project that visualizes consumer buying behavior across leading e-commerce platforms like Amazon and Flipkart.

## Overview

This project presents interactive dashboards for:

- Amazon consumer insights
- Flipkart consumer insights
- Consumer research and decision drivers
- Demographic analysis

It also includes:

- Notebook views with embedded GitHub Gists
- A contribution form for collecting additional data
- Simple navigation for switching between dashboards and sections

## Project files

- `index.html` — main dashboard application
- `README.md` — project documentation

## How to run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Use the sidebar to switch between dashboards, notebooks, and the contribution form.

## Features

- Responsive layout for desktop and mobile
- Dashboard navigation with deep-link support
- Embedded Google Data Studio reports
- Contribution section for collecting user input

## Tech stack

- HTML
- CSS
- JavaScript

## Project purpose

This application helps analyze buying patterns, decision drivers, and demographic trends in consumer shopping behavior.
